# 연차관리 UI 포트폴리오

개인 UI 디자인 포트폴리오입니다. 사내 ERP 프로젝트에서 제가 직접 디자인하고 다듬었던 두 화면 —
**연차관리**(개인 연차 신청/조회)와 **직원 연차 조회**(관리자용 직원별 연차 현황 조회) — 를
회사 코드/브랜딩과 무관하게 새로 재현한 것입니다.

React + TypeScript + Tailwind CSS v4로 만들었고, 실제 백엔드 없이 메모리 내 목(mock) 데이터로만
동작합니다. 등장하는 이름·조직 정보는 모두 가상의 예시 데이터이며, 실제 회사나 서비스와는
관련이 없습니다.

```bash
npm install
npm run dev
```
